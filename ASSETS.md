## External asset inventory

**None.** The repository contains no downloaded images, fonts, audio samples, music, video, third-party code, or data files.

## Authored in this run

- All characters, scenery, mountains, bamboo, structures, rain, mist, lantern glow, UI, effects, awareness indicators, and the original rotational two-bamboo-leaf Takekage kamon are drawn at runtime with project-authored HTML5 Canvas code in `src/render.js`.
- Sword, staff, chain, parry, bell, impact, defeat, win, switch, and UI sounds are synthesized at runtime with project-authored Web Audio oscillators/envelopes in `src/audio.js`.
- Story, names, dialogue, scenario layouts, visual silhouettes, rules, and game code are original to this project.
- System/browser fonts use the local stack `Georgia`, `Times New Roman`, `serif`, and `monospace`; no font files are redistributed.
